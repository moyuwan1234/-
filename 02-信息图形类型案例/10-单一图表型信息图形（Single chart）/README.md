# 单一图表型信息图形（Single chart）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 31 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：围绕一种主要统计或对比图形展开，可用少量附图说明。
- **A 数据逻辑与 B 统计方式**：对象、指标、单位、排序；可用绝对值、排名或尺寸对比。
- **C 视觉编码**：统一尺度的高度/长度、轮廓符号、颜色及数值标签。
- **D 信息架构与 E 视觉叙事**：从标题进入主要图表，按统一尺度比较对象。
