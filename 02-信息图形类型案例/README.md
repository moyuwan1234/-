## 收录约定

1. 每个案例分配 `CASE-XXXX` 编号，分析文档放在 `案例/CASE-XXXX/分析.md`。
2. 案例图片在具有合法使用权限时存放于该案例目录，否则仅保留原始来源链接。
3. 五维分析分别记录观察结果、可核验的统计方法、视觉编码、信息架构与叙事架构。
4. 用 Markdown 相对链接关联 `01-信息图形数据逻辑` 对应概念文档；理论目录不复制图片。
5. 新增或修订案例时，更新索引、对应类型说明、数据逻辑说明及修订记录。

> 目前尚未收到具体案例图片，三类说明文档是待验证的分析框架，不是从案例中得出的实证总结。
