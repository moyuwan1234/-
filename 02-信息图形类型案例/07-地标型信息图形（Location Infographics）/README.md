# 地标型信息图形（Location Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 28 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：以地理位置、地点标记、路线和区域关系为视觉主体。
- **A 数据逻辑与 B 统计方式**：地点、路线、区域、标记；可统计距离、区域指标，但需原始数据。
- **C 视觉编码**：地图轮廓、路径线、地点符号、不同色彩路线及图例。
- **D 信息架构与 E 视觉叙事**：先定位地理范围，再追踪路线、节点和辅助信息。
