# 文字型／列表型信息图形（Informational - List Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 23 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：以文字、栏目、列表及辅助图像解释主题；可嵌入少量统计图。
- **A 数据逻辑与 B 统计方式**：正文条目、分类及说明文字；可按条目计数，不强制量化。
- **C 视觉编码**：标题、文本列、编号、照片和图表构成阅读层级。
- **D 信息架构与 E 视觉叙事**：以中心主题引导，再按文字栏目逐项阅读。
