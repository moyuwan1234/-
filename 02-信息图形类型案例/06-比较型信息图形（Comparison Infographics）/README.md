# 比较型信息图形（Comparison Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 27 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：将两个或多个对象按共同维度对照，突出差异。
- **A 数据逻辑与 B 统计方式**：对象×指标矩阵，须统一指标定义、单位及比较口径。
- **C 视觉编码**：左右镜像、双色编码、对照条形图、圆形标记及人物照片。
- **D 信息架构与 E 视觉叙事**：先识别比较双方，再读对应指标、差异与补充说明。
