# 混合型信息图形（Mixed Charts）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 22 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：将多个统计模块与象形符号整合成统一主题，而非仅并列统计图。
- **A 数据逻辑与 B 统计方式**：按主题模块整理指标及年度；百分比、数量、强度分别使用自己的单位。
- **C 视觉编码**：柱形、圆形比例图、重复人物符号、数字和栏目色块；统一视觉语言但保持不同量纲。
- **D 信息架构与 E 视觉叙事**：环境、交通、客户满意度、工作场所四栏先总览后分项。
