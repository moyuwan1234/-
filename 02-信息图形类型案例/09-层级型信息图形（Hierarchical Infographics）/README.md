# 层级型信息图形（Hierarchical Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 30 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：通过分层、分级或分组结构组织阅读；课件中还包含空间分区的案例。
- **A 数据逻辑与 B 统计方式**：层级节点、级别、分类或分区；若无法核实父子关系，不将分组直接当作树。
- **C 视觉编码**：连续带状层级、上下排列、区域分色及文字注解。
- **D 信息架构与 E 视觉叙事**：由总览进入分级或局部，再理解层间差异。
