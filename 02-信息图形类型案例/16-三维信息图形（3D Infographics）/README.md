# 三维信息图形（3D Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 38 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：用等距、立体剖视或三维分解展示空间结构、场景与信息层级。
- **A 数据逻辑与 B 统计方式**：层、部件、场景与关系；立体大小仅在有量纲依据时编码数量。
- **C 视觉编码**：等距立体、分层爆炸图、引线、色彩和空间留白。
- **D 信息架构与 E 视觉叙事**：先以整体立体形态吸引注意，再逐层读取功能及细节。
