# 流程图型（Process Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 26 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：将步骤、阶段、路径与依赖关系视觉化，强调先后和操作逻辑。
- **A 数据逻辑与 B 统计方式**：阶段节点、连接边、步骤标签；时长等有数据才统计。
- **C 视觉编码**：曲线路径、箭头、节点、等距插图和分支连线。
- **D 信息架构与 E 视觉叙事**：沿路径逐步浏览，从起点到目标或循环反馈。
