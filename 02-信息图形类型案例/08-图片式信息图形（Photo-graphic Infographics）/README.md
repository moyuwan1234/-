# 图片式信息图形（Photo-graphic Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 29 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：以照片为主要视觉材料，将数字、统计图和文字嵌入真实场景或照片。
- **A 数据逻辑与 B 统计方式**：图片对象、主题、指标、标注位置；按实际数据进行比较。
- **C 视觉编码**：照片背景、叠加图标和数据标签、照片裁切成条形或区域。
- **D 信息架构与 E 视觉叙事**：以场景形成主题认知，再读取局部叠加数据。
