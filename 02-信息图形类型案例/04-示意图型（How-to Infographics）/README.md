# 示意图型（How-to Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 25 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：以图解展示对象构成、操作或制作方式，重在看懂怎样完成。
- **A 数据逻辑与 B 统计方式**：材料、部件、步骤与对应说明；可用数量、份量等，课件未提供可复核数据表。
- **C 视觉编码**：爆炸图、分层食材、引线、图标与标签。
- **D 信息架构与 E 视觉叙事**：从整体或材料分解切入，逐层呈现制作关系。
