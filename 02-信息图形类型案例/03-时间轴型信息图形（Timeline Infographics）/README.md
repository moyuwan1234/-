# 时间轴型信息图形（Timeline Infographics）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 24 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：以时间顺序和阶段节点构成叙事主轴，允许非直线构图。
- **A 数据逻辑与 B 统计方式**：年份、事件、阶段；图中节点有明确先后但不能仅凭距离推定持续时间。
- **C 视觉编码**：圆环时间路径、红色年份、建筑照片与说明文字。
- **D 信息架构与 E 视觉叙事**：中心人物和地图建立背景，沿环状年份读建筑历程。
