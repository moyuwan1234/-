# 文字可视化型（Visualized Text）

来源：用户上传《第三讲-信息图形类型学(1).pptx》第 32 页，3-6 常用信息图形种类。中文译名补充处以 PPT 英文原名为准；路径中的斜线改用全角或连字符。

## 类型说明与案例归纳（2026-11-24）

- **类型定义**：将文字概念转化为视觉节点、符号、图形或关系网络；区别于以长文本为主的列表型。
- **A 数据逻辑与 B 统计方式**：概念、标签、关系与分组；若圆面积对应数量，须核对图例。
- **C 视觉编码**：文字图标化、圆节点、连线、色彩分组、字体层次。
- **D 信息架构与 E 视觉叙事**：先识别主要概念，再沿关系或大小层级探索。
