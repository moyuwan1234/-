# ISOTYPE｜基础设计方式标签

**标签名：** `ISOTYPE`  
**分类维度：** 基础设计方法／视觉编码（跨类型标签）  
**定位：** ISOTYPE（International System of Typographic Picture Education）是一种通过系统化象形符号传达信息的方法。在本仓库中，它不是第17种信息图形类型，也不替代五种数据逻辑；可与原有16种表现类型交叉使用。

## 方法原则

- 将复杂对象抽象为易识别、统一且具有语义的象形符号。
- 以一致的形态、比例、网格及排列方式形成系统化视觉语言。
- 当符号用于统计数量时，以等大的符号重复表示数量，注明每个符号代表的单位；必要时说明部分符号或舍入规则，而不是任意放大图标。
- 将符号、文字、图例及统计图形结合，支持读者理解与比较。
- 普通装饰图标、品牌标志或任意插画不自动等同于 ISOTYPE。

## 标签判定规则

| 状态 | 判断依据 |
| --- | --- |
| ISOTYPE | 有明确来源证明采用该方法，或经人工核验符合其系统化符号表达及相关编码原则；记录证据 |
| ISOTYPE候选 | 图面观察到相关特征，但方法依据、数量单位或符号语义仍待核验 |
| 不适用 | 无相关证据，或仅使用装饰性图标 |

标签为可叠加的独立维度。同一个案例仍按原有类型归档，只在标签索引引用，不复制原图与分析文档。

## 交叉使用示例（方法示意，非真实案例）

| 原有类型 | ISOTYPE式方法应用 |
| --- | --- |
| 混合型信息图形 | 象形符号配合统计图形进行数量比较 |
| 比较型信息图形 | 使用等大重复符号表达不同对象的数量 |
| 时间轴型信息图形 | 使用统一符号表示事件类别，配合年份与时间轴 |
| 文字型／列表型信息图形 | 用系统化符号辅助语义表达与阅读 |
