## 类型说明与案例归纳（2026-11-24）

- **类型定义**：通过剖视、解剖、局部放大或结构分解解释对象内部关系。
- **A 数据逻辑与 B 统计方式**：对象、部件、位置、功能与从属关系；不必包含定量数据。
- **C 视觉编码**：结构插图、切面、引线、编号、局部细节。
- **D 信息架构与 E 视觉叙事**：先展示整体，再以标注引导到各部件和功能。
