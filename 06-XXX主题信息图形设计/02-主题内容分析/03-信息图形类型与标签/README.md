# 03-信息图形类型与标签

从[16种信息图形类型](../../../02-信息图形类型案例/README.md)中判断适用类型，例如混合型、文字型／列表型、时间轴型、照片型（图片式）、比较型、流程图型、地标型等。

| 标签维度 | 候选标签 | 选择依据 | 最终标签 |
| --- | --- | --- | --- |
| 数据逻辑 | 编年型、编目型等 | | |
| 表现类型 | 文字型、照片型、混合型等 | | |
| 图形技法 | 词云图、地图、条形图、时间轴等 | | |
| 视觉风格 | 平面、照片、插画、手绘、三维等 | | |

词云图需具备明确的文本词频或权重依据。区分数据逻辑、表现类型、图形技法及视觉风格。
