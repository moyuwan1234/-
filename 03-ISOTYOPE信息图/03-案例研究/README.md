# 03-案例研究

按照统一标准研究历史 ISOTYPE 作品及当代应用案例。

## 案例分类

- 历史案例：维也纳图画统计、ISOTYPE 展览图表与教育出版物。
- 当代应用：采用系统化图符表达数据或信息的作品。
- 候选案例：图面有相关特征但仍需核验方法和出处，不直接认定为 ISOTYPE。

## 案例分析模板

| 维度 | 记录内容 |
| --- | --- |
| A 基本数据逻辑 | 对象、变量、关系与数据结构 |
| B 统计方式 | 指标、单位、重复数量及计算 |
| C 视觉编码 | 图符原型、抽象、网格、色彩、数量映射 |
| D 信息架构 | 分组、比较、排列、图例 |
| E 视觉叙事 | 阅读路径、核心信息与公众理解 |
| F 证据与实践 | 资料来源、授权、设计启示及待验证问题 |
