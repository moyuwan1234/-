# 04-设计实践

将 ISOTYPE 方法用于主题信息图形设计，并记录验证与迭代。

## 实践流程

1. 确定主题、目标受众与叙事问题。
2. 采集真实数据，明确变量、口径及来源。
3. 提取对象特征，绘制图符草案并统一视觉网格。
4. 确定计量单位、重复规则和图例；将图符与统计图形及文字结合。
5. 搭建版式，检查分组、识别性、阅读路径和数据准确性。
6. 比较备选设计，记录用户测试与改进结果。
7. 保存草图、SVG 或其他源文件、成品、数据及版本记录，回写设计方法。
