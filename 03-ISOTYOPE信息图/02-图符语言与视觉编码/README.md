# 02-图符语言与视觉编码

建立象形符号系统、数据映射规范及视觉组织方法。

## 图符语言

- 从对象提取具有辨识度的轮廓、结构与特征，减少无意义细节。
- 统一图符的网格、比例、笔画、视觉重量与色彩。
- 同一语义保持图符一致；类别差异使用可辨识的形状、颜色或标签。
- 图符不是单纯装饰；需明确语义、数据或叙事作用。

## 数量编码

定量表达时优先使用等大图符的重复，定义一个图符所代表的数量；必要时注明余数、部分符号或舍入规则。避免仅将图符放大造成面积误读。纯语义图符不必对应数量，须与定量编码区分。

**方法示例（非真实统计）：** 设一个符号代表100人，500人对应5个符号，300人对应3个符号。

| 变量 | 图符编码 | 设计与核验要求 |
| --- | --- | --- |
| 对象类别 | 形状、图符 | 语义一致且可识别 |
| 数量 | 等大重复图符 | 明确单位、图例、余数 |
| 类别区分 | 色相、形状 | 不仅依赖颜色 |
| 时间与地点 | 位置、排列、文字 | 时间尺度与地理位置真实 |
| 分组与关系 | 间距、区域、连接 | 参考格式塔规则 |
