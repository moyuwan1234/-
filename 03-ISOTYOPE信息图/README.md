# 03-ISOTYOPE信息图

研究图像符号、重复单位、数量映射及跨语言视觉表达。

## 基础设计方式定位

ISOTYPE 是可跨多种信息图形类型使用的基础设计方式，不是本仓库的独立信息图形类型。
