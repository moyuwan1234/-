# 01-历史文献

研究 ISOTYPE 的历史、代表人物、原始文献及学术来源。

## 历史背景

ISOTYPE（International System of Typographic Picture Education）源自20世纪20年代维也纳的图画统计方法。奥托·纽拉特（Otto Neurath）推动其理论与社会教育目标；玛丽·纽拉特（Marie Neurath，原姓 Reidemeister）参与信息转换与视觉教育；格尔德·阿恩茨（Gerd Arntz）参与图符体系的设计。方法在20世纪30年代发展为 ISOTYPE，后来延伸至出版与公众教育。
