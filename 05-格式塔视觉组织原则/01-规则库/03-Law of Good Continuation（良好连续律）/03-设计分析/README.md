# 良好连续律｜设计分析

## A 基本概念

视觉系统倾向于将沿平滑方向延伸的元素感知为连续的轮廓、线条或路径。

## B 视觉特征

方向、对齐、曲率和切线连续性引导视线追踪路径，辅助辨认交叉关系。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

时间轴、流程图、地理路线图、关系网络图。

减少无意义的交叉和急转折；真实分叉处设置节点和方向提示。

## F 案例验证与风险

线条在交叉处可能被误读为连接；连续的形状不能代替实际关系证据。
