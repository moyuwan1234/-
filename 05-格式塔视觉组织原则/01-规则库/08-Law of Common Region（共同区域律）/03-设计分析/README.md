# 共同区域律｜设计分析

## A 基本概念

位于同一明确边界或视觉区域内的元素，更容易被感知为同一组。

## B 视觉特征

容器、背景色块和边框建立共同空间归属，可与接近或相似线索相互作用。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

模块化信息图、数据看板、地理区域划分、卡片式编目。

优先用轻量背景和留白划分模块，避免过多边框；明确区域语义。

## F 案例验证与风险

不同类别被置入同一容器，可能被误认具有共同归属。
