# 同步律｜设计分析

## A 基本概念

在同一时间发生状态变化的元素，即使具体变化形式不同，也可能被知觉为相关的一组。

## B 视觉特征

强调变化的时间一致性，与共同命运律关注运动方向等共同变化关系有所区别。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

交互式信息图、动态统计图、动画叙事、多图表联动。

用同步高亮建立同一筛选条件下的关联；避免无意义闪烁，提供可暂停或静态替代。

## F 案例验证与风险

同时变化不等于真实因果关系；时间不同步可能影响信息判断。
