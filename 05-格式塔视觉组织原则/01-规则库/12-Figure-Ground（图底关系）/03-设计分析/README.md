# 图底关系｜设计分析

## A 基本概念

视觉系统将场景组织为相对突出的图形主体及其背景；特定条件下图底角色可以转换。

## B 视觉特征

边界归属、明暗、色彩、形状和空间关系共同影响主体与背景的分离。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

地图重点区域、核心数据突出、负空间设计、信息图形视觉中心。

建立清晰的主体背景对比，弱化无关装饰；检查小字号及色觉可辨性。

## F 案例验证与风险

低对比度或过强背景会掩盖关键数据；图底可逆图案可能造成歧义。
