# Gestalt设计实践规范

1. 确定设计任务、数据关系、受众及阅读问题。
2. 选择对应原则，写清知觉线索与预期效果，不能以知觉关系替代真实数据关联。
3. 保存原始方案与改进方案，尽量控制其他变量，记录配色、间距、线条、字号或动画变化。
4. 设计验证任务：分类识别、图表读取、关系追踪、核心数据定位等；按需记录准确率、完成时间及定性反馈。
5. 记录受众、样本、日期、测试条件、数据与限制。未测试时明确标为建议，不虚构结果。
6. 将实践结论与案例证据回写对应原则，并关联[06设计实践](../../06-XXX主题信息图形设计/README.md)及[02案例库](../../02-信息图形类型案例/README.md)。
