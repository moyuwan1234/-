# 08-标准化与尺度

## 概念与计算

z=(x−均值)/标准差；min-max=(x−min)/(max−min)，分母须非零。人均或密度指标用合理人口或面积作分母。

## 示例（模拟数据）

10、20、30 做 min-max 得0、0.5、1。
