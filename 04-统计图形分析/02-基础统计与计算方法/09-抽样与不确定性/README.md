# 09-抽样与不确定性

## 概念与计算

记录抽样框、抽样方式、有效样本量及偏差。误差线应明确是标准差、标准误、置信区间还是其他量。经典独立同分布样本均值的标准误为 s/√n；正态总体未知方差的均值区间可用 t 分布。

## 示例（模拟数据）

n=25、s=10，标准误2；95%区间仍需相应临界值与模型条件。
