# 03-方差与标准差

## 概念与计算

总体方差 Σ(x_i−μ)²/N；样本方差 Σ(x_i−x̄)²/(n−1)，n>1。标准差是对应方差平方根，单位与原数据相同。

## 示例（模拟数据）

2、4、6：样本方差4，样本标准差2。
