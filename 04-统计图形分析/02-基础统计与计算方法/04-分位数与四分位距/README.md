# 04-分位数与四分位距

## 概念与计算

Q1、Q2、Q3 分别为25%、50%、75%分位数；IQR=Q3−Q1。注明分位数算法；1.5 IQR规则提供异常线索而非错误判定。

## 示例（模拟数据）

1、2、3、4、5：线性插值 Q1=2，Q2=3，Q3=4，IQR=2。
