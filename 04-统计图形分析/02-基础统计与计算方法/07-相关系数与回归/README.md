# 07-相关系数与回归

## 概念与计算

Pearson r=Σ(x−x̄)(y−ȳ)/√(Σ(x−x̄)²Σ(y−ȳ)²)；常量列未定义。线性回归拟合 y=a+bx，最小化平方残差；需检查模型假设。

## 示例（模拟数据）

x=[1,2,3]、y=[2,4,6]，r=1、斜率2、截距0；不证明因果。
