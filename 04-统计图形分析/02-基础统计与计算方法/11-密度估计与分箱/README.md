# 11-密度估计与分箱

## 概念与计算

直方图不等宽箱用频数密度或概率密度并区分分母。核密度估计 f(x)=ΣK((x−x_i)/h)/(nh)，h为正带宽。

## 示例（模拟数据）

等宽箱[0,10)有4项，频数密度0.4项/单位；核密度与频数不同。

## 适用图形

直方图、密度图、小提琴图。参见[统计图形库](../../01-统计图形库/README.md)。
