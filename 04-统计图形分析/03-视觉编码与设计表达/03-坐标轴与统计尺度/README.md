# 03-坐标轴与统计尺度

## 设计原则

柱形长度通常从零基线起算；折线、散点可用合理非零范围但清楚标注。对数轴要求适用的正值数据与明确刻度，双轴慎用。时间间隔与空间比例须真实或注明示意。
