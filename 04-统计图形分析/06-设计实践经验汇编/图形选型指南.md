# 图形选型指南

| 问题 | 推荐起点 | 需核验 |
| --- | --- | --- |
| 比较量值 | 条形图、棒棒糖图 | 同口径、基线 |
| 看名次 | 排序图、排名变化图 | 并列规则、时间 |
| 相对基准 | 发散图、子弹图 | 目标值与单位 |
| 观察分布 | 直方图、箱线图 | 分箱与分位数 |
| 看时间变化 | 折线图、时间柱状图 | 时间尺度、缺失 |
| 整体构成 | 堆叠图、饼图 | 分母、互斥完备 |
| 变量关联 | 散点图、热力图 | 配对、样本、非因果 |
| 空间分布 | 设色图、比例符号地图 | 位置与标准化指标 |
| 流动关系 | 桑基图、流向地图 | 流量与方向 |

优先选择与数据和读者任务相匹配的图形，再考虑视觉风格。复杂叙事可混合图形，不以装饰替代数据。详见[图形库](../01-统计图形库/README.md)。
