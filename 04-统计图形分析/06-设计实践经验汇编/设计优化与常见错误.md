# 设计优化与常见错误

| 错误 | 风险 | 改进方案 |
| --- | --- | --- |
| 柱形截断基线 | 长度夸大差异 | 零基线或改点图 |
| 气泡半径正比数值 | 面积夸大 | 半径按平方根映射 |
| 饼图使用不完整总体 | 比例误导 | 核验分母、互斥性 |
| 不等宽直方图直接用频数高度 | 面积错误 | 使用密度 |
| 不注明误差线 | 不确定性误解 | 标明区间类型与样本 |
| 区域总量直接设色 | 大区域或人口偏差 | 按任务规范化或比例符号 |
| 相关解释为因果 | 推论越界 | 明确关联与限制 |
| 装饰图符无计量规则 | 数值误读 | 区分语义符号与计量符号 |

当前为方法建议和假设性错误示例，真实错误案例须另行附证据。
