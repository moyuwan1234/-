# 闭合律｜设计分析

## A 基本概念

轮廓不完整时，视觉系统可能将其组织为完整的知觉形态。

## B 视觉特征

局部轮廓与边界线索支持知觉补全，可用留白、断线及负空间降低视觉冗余。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

图标、区域轮廓、视觉符号、简化插画。

保留辨识对象所需的关键特征，测试简化后的可识别性。

## F 案例验证与风险

缺失的数据不是可自动补全的事实；折线缺失值应明确标记。
