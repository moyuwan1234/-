# 元素连接律｜设计分析

## A 基本概念

原本可分辨的元素通过线条等视觉连接建立关系时，容易被组织为一组。

## B 视觉特征

直接连接可强化成对或网络关系；不同于均匀连接律所强调的连续区域本身的知觉单位。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

网络图、组织架构图、流程图、知识图谱。

注明连线的具体关系；区分有向边、无向边与交叉但不相连的线。

## F 案例验证与风险

连线可能暗示不存在的关联或因果关系。
