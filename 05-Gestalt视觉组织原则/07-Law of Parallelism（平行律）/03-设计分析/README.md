# 平行律｜设计分析

## A 基本概念

具有平行方向关系的线条或轮廓，倾向于被组织为相关的视觉元素。

## B 视觉特征

方向一致和重复线条强化视觉秩序；平行不必然表示数据相关。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

多轨时间轴、平行坐标图、统计图排列、交通线路。

保持相关线条排列一致；通过图例明确不同轨道及尺度。

## F 案例验证与风险

装饰性平行线不能被误读为同一趋势或等量关系。
