# 接近律｜设计分析

## A 基本概念

空间距离较近的元素更容易被感知为同一组。

## B 视觉特征

组内间距与组间间距形成分组线索；在其他属性相近时，距离能够建立信息归属。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

数据分组、图文配对、图例排版、信息模块划分。

同组元素保持较小间距，不同组增加留白；先调整间距，再考虑分割线。

## F 案例验证与风险

图注离其他图表更近时易被误读为其他图表的说明。
