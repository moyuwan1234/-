# 良好形态律｜设计分析

## A 基本概念

在给定条件下，视觉组织倾向于形成相对良好、稳定、规律和完整的知觉形态。

## B 视觉特征

是较广泛的组织倾向，并非单纯追求元素最少；简洁、规则、完整和可理解性需结合实际条件判断。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

数据降噪、复杂信息架构、图标简化、统计图形优化。

减少无效装饰和冗余编码，保留必要的维度、数据和解释。

## F 案例验证与风险

过度简化可能删除重要信息或导致错误结论。
