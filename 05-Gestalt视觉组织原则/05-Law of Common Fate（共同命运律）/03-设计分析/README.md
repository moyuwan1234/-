# 共同命运律｜设计分析

## A 基本概念

具有共同运动方向或一致运动变化的元素，容易被感知为一个整体。

## B 视觉特征

共同运动是关键线索；静态箭头只是在设计中模拟或提示这种关系，不等同于真正的运动刺激。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

人口迁徙图、交通流向、物流网络、动态数据可视化。

同组动态对象采用与真实关系一致的运动方向；静态图使用明确箭头和图例。

## F 案例验证与风险

方向相同不代表存在因果关系；不应虚构流量、速度或路径。
