# 对称律｜设计分析

## A 基本概念

具有镜像或其他对称关系的元素倾向于被感知为统一的知觉结构。

## B 视觉特征

对称轴、对应位置和重复结构帮助识别成对关系及整体轮廓。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

人口金字塔、双对象比较图、结构图、对比式版面。

对称布局可以帮助比较，但必须维持相同尺度及真实数值差异。

## F 案例验证与风险

为追求对称而改动数据长度或面积会误导读者。
