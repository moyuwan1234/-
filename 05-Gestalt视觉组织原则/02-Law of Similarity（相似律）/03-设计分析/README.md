# 相似律｜设计分析

## A 基本概念

颜色、形状、大小、方向或纹理等视觉属性相似的元素，容易被组织为相关的一组。

## B 视觉特征

相同视觉编码帮助读者跨越空间距离识别同类数据，但多个线索可能竞争。

## C 信息组织

识别该原则所作用的信息单位、分组或主体关系；检查与真实数据结构、分类、关联的对应。

## D 视觉叙事

分析阅读起点、视线顺序和视觉重点，区分感知线索与实际信息关系。

## E 应用方法

分类地图、统计图例、ISOTYPE符号系统、编目型信息图形。

同类对象保持一致编码，异类明显区分；重要类别可同时用颜色和形状区分。

## F 案例验证与风险

无关数据共享相同颜色或形状，容易产生错误分组；不能仅凭色相表达有序数值。
