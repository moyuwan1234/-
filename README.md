# 信息图形知识库 · Information Graphics Taxonomy

以数据逻辑与视觉表现类型为双重分类轴，研究信息图形的数据结构、统计方式、视觉编码、信息架构及视觉叙事。

> 研究体系独立整理，目录结构参考 [fengbaifan/Infographic-Style-Repository](https://github.com/fengbaifan/Infographic-Style-Repository)。

## 研究目录

- [01-信息图形数据逻辑](./01-信息图形数据逻辑/README.md) — 五种数据逻辑的 A–E 理论定义；仅保存文字与案例链接
- [02-信息图形类型案例](./02-信息图形类型案例/README.md) — 课件中的16类信息图形、64条案例观察记录及方法归纳
- [03-ISOTYOPE信息图](./03-ISOTYOPE信息图/README.md) — 历史文献、图符语言与视觉编码、案例研究、设计实践
- [04-统计图形分析](./04-统计图形分析/README.md) — 9大类别、36种图形、统计方法、视觉编码、案例及对照实验
- [05-格式塔视觉组织原则](./05-格式塔视觉组织原则/README.md) — 12项规则、概念框架、案例库、跨原则对照实验与实践经验汇编
- [06-XXX主题信息图形设计](./06-XXX主题信息图形设计/README.md) — 八阶段选题设计流程、数据集模板、叙事与视觉编码规范
