# DNA协议

| 类型 | 语义 | 处理 |
|---|---|---|
| core | 核心 | 锁定且无条件生效；候选核心也应在测试中保持 |
| stable | 稳定 | 保留默认关系，允许显式范围内变化 |
| adaptive | 自适应 | 满足条件则执行，缺少匹配时使用通用回退 |
| free | 自由变量 | 描述用户可变内容，不作为风格生成指令 |
| negative | 排斥 | 明确拒绝的风格特征，随适用条件执行 |

每条规则以唯一ID存储；包括双语观察、双语生成指令、允许范围、条件、优先级、证据、置信度和双语验证标准。核心与排斥不得自相矛盾。优先级只用于同类型规则排序，不能让自适应覆盖核心。负向规则不是全部媒介通用禁令，而是目标风格的约束。

## 置信度
high：多张独立样本一致或有明确测量/验证；medium：可见证据较充分但跨主题尚未验证；low：单图推断、遮挡或信息不足。此为定性标签，不是概率。证据分 direct / measured / inferred / hypothetical；示例只能标 hypothetical。

## 冲突
核心与新主题必需属性冲突时暂停并说明，提供保持风格的转译方案；若用户确需改变核心，则创建新风格版本。稳定规则只能在允许范围内变化；同级冲突交由人工复核。编译器不能自动理解所有语义冲突，必须在解析阶段记录并确认。
