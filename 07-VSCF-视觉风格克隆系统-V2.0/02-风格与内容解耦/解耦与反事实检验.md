# 风格与内容解耦

1. 记录参考图 R01...，注明来源、尺寸、同风格组/异常样本。图像本身缺失时停止提取，不补造。
2. 逐图列出内容实体、可见形式、关系结构、叙事推断、偶然缺陷。相同元素不自动等于风格；不同元素共享的表现方法更有价值。
3. 反事实检验：若把原物换成其他类别，特征是否仍有意义？若仍成立，转写为角色或关系规则；若不能，归入主题变量、专项条件或待验证候选。
4. 重复检验：多图比较出现频率、分布和反例；同一系列的重复背景可能仍是题材绑定。单图不得把所有观察认定为稳定规律。
5. 输出：保留规则、移除的原对象、候选规则、适用边界与不确定性。建立反泄漏检查：原图人物、地名、具体建筑、固定道具、文字等不得无故进入通用风格提示词。

## 转换示例（假设）
“红色屋顶是焦点”→“局部高对比强调色用于主题识别性焦点”；“山占画面90%”→“环境主导、主体弱尺度（仅在该风格经证实具有此规律时）”。原始比例可记录为观察值，而非通用参数。

## 数值证据
色板HEX、面积比例、边缘宽度、明暗分布均注明测量方法、坐标/区域、图像分辨率和误差；视觉估计注明 estimate，不伪造精确值。识别艺术来源、心理效应、真实物理材质时明确推断性质。
