# 风格评价与发布门槛（拟议）

| 指标 | 权重 | 评价重点 |
|---|---:|---|
| 风格特征还原度 |25| 参考证据与生成图的可见特征 |
| 核心基因保持度 |20| 核心逐条通过率 |
| 跨主题迁移能力 |15| 异类主题保持风格、不泄漏原题材 |
| 主题自适应能力 |15| 识别性、必要结构、条件规则 |
| 重复生成稳定性 |10| 多次生成的风格保持 |
| 提示词通用性 |10| 无图依赖、跨模型可用范围 |
| 四版本语义一致性 |5| 规则覆盖与实际语义 |

每指标0–4分：0未实现，1严重偏差，2部分符合，3基本符合，4充分符合。加权总分=Σ(等级/4×权重)。未测试标 pending，不以0或满分替代；未完成全部项目不计算正式总分。建议2名独立评审并记录分歧，必要时追加复核。

## 硬性否决
任何必需核心规则违反、排斥规则实质违反、主体必要语义缺失、原图特有对象无故泄漏、四格式遗漏核心、未解决冲突，均判失败，不由总分补偿。核心规则不确定则记录 pending 而不是宣称通过。

## 拟议验收标准
全部适用硬性检查通过，T01–T10完成（无法获得第二模型时标注仅单模型验证，不宣称跨模型通用），每个测试条件按计划完成重复，报告所有失败率；总分≥85/100，单指标≥3/4。上述门槛为设计建议，尚未经数据校准。通过后声明具体测试范围、模型、主题与版本；不承诺未来每次生成一致。
