# 03 视觉抽象程度

字段：`abstraction_level`；规则编号示例：`ABS-001`。

## 观察对象

写实程度、概括、变形、符号化与识别性。

## 提取方法

对照对象的结构特征，观察哪些细节被省略。

## 关系分析

抽象程度影响形态、细节、空间。

## 通用化转换

规定保留结构与省略层级。

## 主题适配

复杂对象保留识别线索；抽象主题不强行具象。

## 排斥条件

无依据增加写实度或失去必要识别性。

## 验证方法

同类及异类对象的概括逻辑一致。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
