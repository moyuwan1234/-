# 02 表现媒介

字段：`medium`；规则编号示例：`MED-001`。

## 观察对象

平面、摄影、绘画、印刷、三维及媒介痕迹。

## 提取方法

检查笔痕、像素、网点、反光与深度线索；区分真实媒介与模拟效果。

## 关系分析

媒介约束线条、光照、纹理。

## 通用化转换

定义渲染方法和媒介特性。

## 主题适配

对象改变仍使用同类媒介；无实体媒介证据不猜工艺。

## 排斥条件

不相容的摄影化、立体化或笔刷。

## 验证方法

媒介特征在新对象上仍可辨识。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
