# 24 主体转译系统

字段：`subject_translation`；规则编号示例：`SUB-001`。

## 观察对象

主体轮廓、内部结构、材质、姿态及概括方式。

## 提取方法

区分角色DNA、语义必需结构和表现语法。

## 关系分析

主体转译调用形态、线条、材质、密度等。

## 通用化转换

定义从对象语义到风格形式的转换算子。

## 主题适配

识别新对象类型、关键特征和复杂度；未知类使用通用回退。

## 排斥条件

原题材泄漏、不可识别或替换成原主体。

## 验证方法

跨类别生成并检查主题识别与风格保持。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
