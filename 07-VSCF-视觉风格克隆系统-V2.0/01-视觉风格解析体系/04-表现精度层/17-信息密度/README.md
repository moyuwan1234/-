# 17 信息密度

字段：`information_density`；规则编号示例：`DEN-001`。

## 观察对象

视觉元素数量、疏密、复杂度、留白分布。

## 提取方法

划分区域，记录元素/纹理密集程度及分析尺度。

## 关系分析

密度与层级、节奏、张力共同作用。

## 通用化转换

定义密度地图或相对分配规律。

## 主题适配

多对象时聚合细节；少对象时避免无意义填充。

## 排斥条件

机械增删细节、背景喧宾夺主。

## 验证方法

按相同分区比较疏密结构。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
