# 18 细节语言

字段：`detail_language`；规则编号示例：`DET-001`。

## 观察对象

细节类型、装饰、重复、符号、局部特征。

## 提取方法

区分识别性细节、装饰性细节和偶然噪点。

## 关系分析

细节与纹理、完成度、锚点相关。

## 通用化转换

提取细节的生成语法与选择标准。

## 主题适配

用新对象的关键结构替代原题材细节。

## 排斥条件

将原物体装饰强加给新主题。

## 验证方法

细节可识别且装饰逻辑一致。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
