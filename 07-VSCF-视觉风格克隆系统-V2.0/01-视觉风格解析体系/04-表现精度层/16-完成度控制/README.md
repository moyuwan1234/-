# 16 完成度控制

字段：`finish_control`；规则编号示例：`FIN-001`。

## 观察对象

刻画深度、概括、未完成感、区域差异。

## 提取方法

比较对象各区表现层数；不把主观百分比当测量。

## 关系分析

完成度与密度相关但不等同。

## 通用化转换

规定刻画层级与省略策略。

## 主题适配

依主题识别需求调整刻画，不改变完成度逻辑。

## 排斥条件

过度精修、非预期粗糙。

## 验证方法

人工检查区域刻画差异及均衡性。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
