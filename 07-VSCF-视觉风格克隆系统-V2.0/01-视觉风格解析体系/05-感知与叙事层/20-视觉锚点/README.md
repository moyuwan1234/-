# 20 视觉锚点

字段：`visual_anchor`；规则编号示例：`ANC-001`。

## 观察对象

首次注意点、次焦点、最终停留点。

## 提取方法

区分推断的注意点与实际眼动；明确依据。

## 关系分析

锚点受颜色、尺度、边缘、叙事控制。

## 通用化转换

定义焦点形成机制与角色。

## 主题适配

新主题选择语义相关焦点而非原物体。

## 排斥条件

焦点偏离或无依据新增强调。

## 验证方法

核对第一焦点及预期停留点；需要时做观看测试。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
