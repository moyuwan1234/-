# 21 视觉路径

字段：`visual_path`；规则编号示例：`PTH-001`。

## 观察对象

入口、引导线、阅读方向、节奏、停留点。

## 提取方法

标记预期路径与支持线索，不能将推断当眼动事实。

## 关系分析

路径与层级、连续性、叙事关系相连。

## 通用化转换

描述路径拓扑与节奏。

## 主题适配

根据新场景的对象关系重建路径。

## 排斥条件

路线冲突、无意义引导。

## 验证方法

人工路径标注与盲评。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
