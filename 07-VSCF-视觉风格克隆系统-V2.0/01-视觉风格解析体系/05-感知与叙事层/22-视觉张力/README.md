# 22 视觉张力

字段：`visual_tension`；规则编号示例：`TEN-001`。

## 观察对象

大小、明暗、动静、满空、冷暖、粗细、规则与例外。

## 提取方法

识别主张力及其两端，区分客观对比与情绪解释。

## 关系分析

张力来自多个视觉系统的关系。

## 通用化转换

保留对比机制与强弱，非固定对象。

## 主题适配

以新对象的对应角色重建对比。

## 排斥条件

无关冲突或过度削弱主张力。

## 验证方法

检查主要对比及叙事作用。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
