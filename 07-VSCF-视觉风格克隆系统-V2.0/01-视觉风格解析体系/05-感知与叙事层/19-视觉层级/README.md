# 19 视觉层级

字段：`visual_hierarchy`；规则编号示例：`HIE-001`。

## 观察对象

主次层级、重量、对比、信息权重。

## 提取方法

先缩略图观察，再核对局部对比和尺寸。

## 关系分析

层级由色彩、构图、密度等共同产生。

## 通用化转换

定义主次关系而非固定某个对象。

## 主题适配

新主题建立对应角色层级。

## 排斥条件

增加多个竞争焦点或抹平层级。

## 验证方法

缩略图及独立观看者判断主次。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
