# 23 情绪与氛围

字段：`mood`；规则编号示例：`MOO-001`。

## 观察对象

整体气质、情绪倾向、叙事立场、余韵。

## 提取方法

先记录视觉证据，再写解释；允许多种解读。

## 关系分析

氛围是色彩、光线、结构等的综合结果。

## 通用化转换

描述产生气质的视觉机制而非仅情绪词。

## 主题适配

区分固定风格气质与新主题情绪，冲突需明确。

## 排斥条件

只堆形容词或情绪导致风格漂移。

## 验证方法

盲评感知与规则是否对应。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
