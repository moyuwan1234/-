# 14 视觉组织系统

字段：`visual_organization`；规则编号示例：`ORG-001`。

## 观察对象

图底、接近、相似、连续、闭合、共同区域等。

## 提取方法

识别实际分组线索，不要求每条原则都出现。

## 关系分析

组织原则与构图、层级、路径相连。

## 通用化转换

定义元素如何成组与区分。

## 主题适配

新对象沿用组织逻辑，信息图优先保持语义可读。

## 排斥条件

无依据增加装饰或破坏分组。

## 验证方法

分组边界与阅读逻辑清晰。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
