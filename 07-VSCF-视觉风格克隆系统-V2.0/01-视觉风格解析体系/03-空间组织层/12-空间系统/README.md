# 12 空间系统

字段：`space`；规则编号示例：`SPA-001`。

## 观察对象

透视、遮挡、层次、视点、纵深与平面关系。

## 提取方法

检查汇聚线、重叠、明暗和大小递减。

## 关系分析

空间与光线、尺度、边缘共同组织深度。

## 通用化转换

定义平面化或纵深逻辑与视点约束。

## 主题适配

根据新场景使用一致空间表达；无场景不强加纵深。

## 排斥条件

凭空增加透视或错误空间混合。

## 验证方法

不同场景的空间语法保持一致。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
