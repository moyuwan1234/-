# 11 构图系统

字段：`composition`；规则编号示例：`COM-001`。

## 观察对象

主次位置、画幅、留白、平衡、裁切。

## 提取方法

记录归一化位置和占区；区分固定模板与样本偶然布局。

## 关系分析

构图协调尺度、路径、图底关系。

## 通用化转换

提取布局原则及可允许的变体。

## 主题适配

根据主题及画幅重排，保留布局逻辑。

## 排斥条件

机械复制原图坐标或破坏层级。

## 验证方法

在横竖画幅复核布局与留白。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
