# 13 尺度系统

字段：`scale`；规则编号示例：`SCA-001`。

## 观察对象

主体占比、相对大小、比例夸张。

## 提取方法

明确面积或高度口径；有测量才记录数值。

## 关系分析

尺度影响张力和视觉权重。

## 通用化转换

以关系和适用范围表达尺度。

## 主题适配

按主体数量、画幅变化调整；必要时锁定标志性比例。

## 排斥条件

普遍套用80%–95%环境占比。

## 验证方法

按同一口径比较比例及张力。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
