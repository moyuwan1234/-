# 04 色彩系统

字段：`color`；规则编号示例：`COL-001`。

## 观察对象

色相、明度、饱和度、色温、配色面积与角色。

## 提取方法

分区抽样，区分背景、主色、辅色、强调色；无像素测量不填精确值。

## 关系分析

色彩角色与锚点、层级、光线相互作用。

## 通用化转换

提取调色板、角色关系及色彩边界。

## 主题适配

按语义角色分配颜色，必要时保持固有色可识别性或标记冲突。

## 排斥条件

无依据增加色相、饱和度、渐变。

## 验证方法

有测量时比较色域和面积；同时人工核对角色关系。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
