# 09 材质系统

字段：`material`；规则编号示例：`MAT-001`。

## 观察对象

物体质感、反射、透明、粗糙及表面处理。

## 提取方法

区分对象自身材质与绘制媒介；避免推断实际工艺。

## 关系分析

材质表现依赖光线、形态、纹理。

## 通用化转换

提取材质的视觉表达方法，不锁定对象材质。

## 主题适配

新材质用同一表现方法呈现，必要功能特征保留。

## 排斥条件

给所有对象强加原图材质。

## 验证方法

多种材质可区分且绘制语法统一。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
