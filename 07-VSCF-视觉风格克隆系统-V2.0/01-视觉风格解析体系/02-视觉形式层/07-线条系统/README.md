# 07 线条系统

字段：`line`；规则编号示例：`LIN-001`。

## 观察对象

线宽、曲直、断续、压力、端点、节律、颜色。

## 提取方法

分别检查外轮廓、结构线、纹理线；相对画幅记录宽度。

## 关系分析

线宽等级控制边缘与注意力。

## 通用化转换

定义轮廓与内部线关系，规定有线或无线。

## 主题适配

依对象复杂度调节线数量，不任意改变线型。

## 排斥条件

错误线宽、端点、线条质感。

## 验证方法

对照线宽层级、连续性和节奏。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
