# 08 笔触系统

字段：`brushwork`；规则编号示例：`BRU-001`。

## 观察对象

笔痕尺度、方向、叠加、透明度、覆盖率。

## 提取方法

放大查看笔触与对象体积关系；不可见不推测。

## 关系分析

笔触与媒介、纹理、完成度关联。

## 通用化转换

规定笔触组织与覆盖方式。

## 主题适配

随新表面形状调整方向但保留笔触语言。

## 排斥条件

混入无关笔刷或过度磨平。

## 验证方法

局部放大检查笔痕一致性。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
