# 06 形态系统

字段：`shape`；规则编号示例：`SHP-001`。

## 观察对象

轮廓几何性、有机性、圆角、夸张、比例变形。

## 提取方法

对照外轮廓、内部形面及重复形状。

## 关系分析

形态语言关联抽象、线条、尺度。

## 通用化转换

描述简化、分解、变形或组合算子。

## 主题适配

先保留新对象必要结构，再使用同一形态语法。

## 排斥条件

照搬原对象轮廓或改变形态语法。

## 验证方法

新对象可识别且轮廓语言一致。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
