# 10 纹理系统

字段：`texture`；规则编号示例：`TEX-001`。

## 观察对象

颗粒、纸纹、网点、噪点、频率、分布。

## 提取方法

比较平坦区与主体区；区分压缩伪影。

## 关系分析

纹理影响媒介、细节与信息密度。

## 通用化转换

规定纹理尺度、强度、分布及禁用项。

## 主题适配

随分辨率及局部对象调整，不让纹理吞没识别特征。

## 排斥条件

压缩伪影、无依据随机纹理。

## 验证方法

同画幅归一化后比较纹理观感。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
