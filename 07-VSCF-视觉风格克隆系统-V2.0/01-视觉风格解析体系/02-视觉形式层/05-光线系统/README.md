# 05 光线系统

字段：`lighting`；规则编号示例：`LGT-001`。

## 观察对象

光源方向、光质、阴影、反射、对比、光色。

## 提取方法

识别高光与阴影证据；无光照表现标不适用或明确无光影为规则。

## 关系分析

光线影响体积、材质与空间。

## 通用化转换

定义照明逻辑而非绑定具体窗户或太阳。

## 主题适配

新物体沿用光质与明暗关系；平面风格维持无光影。

## 排斥条件

无依据新增写实阴影或光效。

## 验证方法

检查阴影一致性、明暗结构与光线叙事。

## 记录要求

每项先记录证据位置与可见事实，再记录推断、候选规则、基因分类、适用条件与允许变化。证据不足标 unknown，不适用标 not_applicable 并解释，不能以默认值冒充提取。单图候选规则须经迁移实验确认。
