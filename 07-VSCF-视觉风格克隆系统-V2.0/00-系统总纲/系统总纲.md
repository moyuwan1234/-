# VSCF 2.0 系统总纲

## 目标
从参考视觉作品逆向建模可观察的风格规律，独立存储风格 DNA，支持原主题复现、同类变体、异类迁移及多主题扩展。以高保真为目标，不宣称提示词可保证像素级复现或跨模型完全一致。

## 架构
输入（单图/多图）→ 24维逆向分析 → 风格内容解耦 → DNA提取 → 规则建模 → 通用化 → 主题自适应 → 同源四版本 → 校验迭代。8个功能模块沿用确认版；24维属于通用分析坐标，不是24条强制风格规则。

## 术语
- 风格：表现对象的稳定视觉语法；内容：被表现的语义对象、场景、文字与情节。
- 结构：元素的组织关系；可属于风格，也可由具体任务决定。
- 叙事：张力、路径、停留点和余韵；区分固定叙事立场与新主题意图。
- 偶然信息：噪点、生成错误、样本特有构图等，未经证实不固化。
- 角色DNA：对象身份约束，与风格DNA独立；仅在系列任务中另行加载。
- 权威DNA：规则列表的唯一来源；四种提示词为派生输出，不单独维护。

## 原则
P01精准提取；P02证据优先；P03主题解耦；P04核心锁定；P05自适应；P06通用复用；P07同源输出；P08模型参数隔离；P09可追溯；P10实验验证。

## 状态
模板(draft) → 候选(candidate) → 实验中(testing) → 已验证(validated)；失效(deprecated)。示例为 demonstration，不代表验证。修改核心规则增加主版本；增加兼容规则增加次版本；文字纠错且语义不变增加修订版本。每次变更保留旧资产、变更理由、测试编号。

## 适用边界
插画、平面、摄影、三维、字体均可用通用维度，但不适用项允许明确跳过。字体扩展应另存字形结构、字面率、字距、可读性；海报扩展应另存网格、文字与图形关系；信息图扩展应另存编码与数据正确性。扩展不得覆盖核心规则，专业正确性不可用风格分数代替。
