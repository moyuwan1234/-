# 跨主题迁移实验矩阵

| ID | 变化 | 控制条件 | 检查 |
|---|---|---|---|
| T01 | 原主题 | 同模型同设置 | 还原度 |
| T02 | 同类主体 | 风格不变 | 同类复用 |
| T03 | 异类主体（至少3类） | 风格不变 | 迁移与识别 |
| T04 | 场景改变 | 主体与风格不变 | 环境适配 |
| T05 | 复杂度低/中/高 | 类别与风格不变 | 密度适配 |
| T06 | 多次随机生成 | 每次记录种子或不可用 | 稳定性 |
| T07 | 横/竖/方画幅 | 主题与风格不变 | 构图适配 |
| T08 | 四种提示词 | 主题与设置不变 | 格式一致性 |
| T09 | 跨模型（至少2种若可用） | 同DNA，适配器独立 | 模型通用性 |
| T10 | 与核心冲突的主题 | 只改变冲突条件 | 拒绝/显式派生 |

建议每种生成条件至少3次，记录所有结果而非只挑最佳。随机种子跨模型不可等同；不可用时记录原因。先做同模型单变量实验，再做跨模型。T10为逻辑测试，不必生成违反核心的图。
