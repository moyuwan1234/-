# VSCF 2.0 通用视觉风格克隆与自适应迁移系统

本仓库为用户确认架构的完善版（设计规范 + 可运行提示词编译原型），未上传 GitHub。目标：精准提取、解耦、复用、迁移、自适应和同源四版本输出。不宣称已完成图像分析模型或经过视觉验证。

## 快速开始
1. 阅读 `00-系统总纲/系统总纲.md` 和 `12-系统工作流与执行指令/系统执行指令.md`；将主控指令交给能够读取图像的AI并提供参考图。
2. 按24维手册填写权威DNA JSON；使用 `06-JSON结构化协议/通用JSON模板.json`。模板不可直接执行；示例可运行但仅为假设。
3. 安装 Python 3.10+ 和 `jsonschema`（`pip install -r requirements.txt`）。执行以下命令（从仓库根目录）：

```bash
python "12-系统工作流与执行指令/compile_prompts.py" "08-风格克隆案例库/STYLE-0001-极简黑白线描/04-核心风格DNA.json" --out output-general
python "12-系统工作流与执行指令/compile_prompts.py" "08-风格克隆案例库/STYLE-0001-极简黑白线描/04-核心风格DNA.json" --theme "08-风格克隆案例库/STYLE-0001-极简黑白线描/05-主题输入示例.json" --out output-bound
python "12-系统工作流与执行指令/test_compiler.py"
```

编译器确定性选择规则并输出4文件及检查清单；不是图像生成器，不自动推理未结构化的语义冲突。先由AI/人工分析并填写冲突记录，未解决冲突会阻止绑定编译。然后按实验库运行视觉生成与评估。
