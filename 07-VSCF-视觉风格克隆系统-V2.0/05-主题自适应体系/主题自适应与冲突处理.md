# 主题自适应协议

输入：主题、主体、场景、主体类别、复杂度、画幅、必要识别特征。输出：选中规则ID、保留规则、条件性调整、排斥约束、冲突记录。

| 类别 | 主体语义提取 | 可适配内容 |
|---|---|---|
| architecture | 结构、门窗、屋顶、比例 | 结构线、空间布局 |
| plant | 生长方向、叶形、分枝 | 轮廓、纹理密度 |
| person | 姿态、人体结构、身份特征 | 局部概括、动作 |
| animal | 物种外形、姿态 | 毛发/鳞片表现 |
| product | 功能结构、识别特征 | 几何组织、材质 |
| landscape | 地形、层次 | 纵深或平面组织 |
| abstract | 概念关系、视觉符号 | 形态映射、组织 |
| mixed / other | 识别多类关系或未知对象 | 通用回退；人工复核 |

以上为语义提取提示，不是固定视觉风格。实际表现必须使用该资产的DNA。

## 执行顺序
锁定核心 → 提取新主题必要特征 → 检查冲突 → 加载稳定规则 → 匹配 adaptive 与 negative 条件 → 应用通用回退 → 输出四版本。条件以类别与复杂度的枚举表达；未设置条件为空数组，表示任意。画幅作为主题变量，不强制固定；若风格本身锁定画幅则报告冲突。未知类别用 other，不能猜测对象类别。

## 冲突记录
用户要求/涉及规则ID/冲突原因/保持风格的替代表达/是否解决。禁止静默解除核心；尚未解决时不生成可执行提示词。
